# Traiproject Tap

## How do I install these formulae?

`brew install traiproject/tap/<formula>`

Or `brew tap traiproject/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "traiproject/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
